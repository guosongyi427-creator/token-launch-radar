How the value is worked out — and tested

launch value = exp(intercept + slope × ln(TVL) + category log-adjustment) × growth multiplier
implied value = launch value × launch odds

Out-of-sample test — the fitted curve against a flat multiple

Median absolute log error: a value of 1.2 means the typical prediction is off by a factor of about e1.2 ≈ 3.3. The fit is weak in absolute terms (R² ≈ 0.19) — the test is shown so you can see exactly how weak, and that it still beats a flat multiple out of sample.

Launch odds fall with no-token age

Odds = a ridge logistic regression on all 758 protocols: P(still pre-token) from log TVL and log(1 + age), standardised, L2 penalty 10. The fitted age weight is negative, so the odds fall smoothly with no-token age instead of in bucket steps; protocols with no listed date use 1,000 days. Growth is not in the odds — it is already in the launch value. Odds are clamped to 0.05–0.95.

    Farm verdicts — netted to the dollar

    Expected farm value = implied value × 10% farmer share ÷ farmers. Farmers are a stated proxy, not a measured headcount: 500 for rank 1, +10 per rank. Cost = capital (by TVL) + gas + time at $25/hour. Verdict: SKIP if net ≤ $0, THIN if $0 < net ≤ $250, FARM otherwise. Time is charged at $25/hour inside the net, so net > $0 already implies value/hour > $25; THIN is the thin-margin band, where a small rise in farmers flips the verdict to SKIP.

    Implied value is this model's estimate from TVL, growth, age and the live-token record. It is not a price, not a prediction that a token will be issued, and not advice.
